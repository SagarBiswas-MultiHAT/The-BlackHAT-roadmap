# Visual Assets & Architectural Diagrams

## Overview

This directory contains the visual design system, cybernetic HUD banner, and over 150 high-resolution architectural diagrams and execution flowcharts for **The BlackHAT Roadmap**.

## Directory Structure

- `banner.svg`: Main cybernetic HUD repository banner.
- `diagrams/`: Phase-aligned architectural diagrams, memory layout models, network topologies, attack kill chains, and decision trees covering Phase -1 through Phase 6.
